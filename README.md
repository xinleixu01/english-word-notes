# Word Notes · 10.20

50 个英语单词，按主题整理。每个单词独立卡片：词性、英式音标、释义、搭配、例句、用法笔记。支持英美语音、搜索、隐藏释义和逐张背词，适配手机。

## GitHub Pages

将本目录内容上传到 GitHub 仓库根目录。在 Settings → Pages 中选择 Deploy from a branch，分支选择 main，文件夹选择 /(root)。保存后使用 GitHub 显示的网站地址。

普通个人 GitHub Pages 网站公开可访问；私有仓库并不自动使网页私有。发布前确认接受公开访问。

## 文件

- index.html：页面布局与样式
- data.js：词汇内容
- app.js：搜索、卡片与发音交互
- .nojekyll：直接发布静态文件

发音使用浏览器语音合成，设备需支持英语语音；不依赖 API 密钥。
